Файл README

-----------------------------------------
	О ПРОГРАММЕ:

	Программа 'lss_19_06' предназначена для решения системы линейных алгебраических уравнений (СЛАУ)
	методом Гаусса-Жордана с выбором главного элемента по матрице.

-----------------------------------------

	ГРАФИЧЕСКИЙ ИНТЕРФЕЙС:

	Графияеский интерфейс ограничен консолью. Ввод и вывод данных осуществляется через файлы.

---

Синтаксис запуска программы:

	lss_19_06 [входной_файл] [выходной_файл] [опции]

! В данной программе порядок не имеет значения. В качестве названия файлов могут быть разпознаны только
два. Опции определяются знаком "-" перед буквой. 

---

	По умолчанию:

	lss_19_06_in.txt    - входной файл
	lss_19_06_out.txt   - выходной файл

---

	Программа имеет следующие команды(опции):

	-d — выводить отладочные сообщения.
	-e — выводить сообщения об ошибках.
	-p — печатать матрицу `A` и вектор `B` на экран.
	-t — выводить время выполнения.
	-h, -? — вывести справку и выйти.

---

	Пример:

	lss_19_06

	lss_19_06 input.txt output.txt -d -e -p -t

	lss_19_06 -h

	lss_19_06 ?

----------------------------------

	ФОРМАТ ВХОДНОГО ФАЙЛА:

	I - ФОРМАТ ПОЛНОЙ МАТРИЦЫ

	   n
	   a_1_1 a_1_2 ... a_1_n
	   a_2_1 a_2_2 ... a_2_n
	   .....................
	   a_n_1 a_n_2 ... a_n_n
	   b_1
	   b_2
	   ...
	   b_n


	n — исло уравнений.
	a_ij — элементы матрицы коэффициентов `A` (записываются построчно).
	b_i — элементы вектора правых частей `B`.

	Пример:

	4
	2 5 7 -2
	3 -4 0 1
	1 2 -1 4
	5 0 6 -3
	-2
	22
	3
	44

---

	II - ФОРМАТ ТРЕХЛЕНТОЧНОЙ МАТРИЦЫ

	  n
	   a_1 c_1
	   d_1 a_2 c_2
	   d_2 a_3 c_3
	   ...........
	   d_{n-2} a_{n-1} c_{n-1}
	   d_{n-1} a_n
	   b_1
	   b_2
	   ...
	   b_n

	n - число уравнений. 
	a_i - элементы главной диагонали матрицы 'A'. 
	c_i - элементы верхней диагонали матрицы 'A'. 
	d_i - элементы нижней диагонали матрицы 'A'. 
	b_i - элементы вектора правой части 'B'.


	Пример:

	5
	5 1 
	2 3 7 
	4 6 1
	5 2 3
	4 8
	1
	2
	3
	4
	5

----------------------------------

	ФОРМАТ ВЫХОДНОГО ФАЙЛА:

	В выходной файл записывается решение СЛАУ в следующем формате:

	n
	x_1
	x_2
	...
	x_n

	n - число уравнений.
	где x_i - i-й элемент вектора решения X.

	Пример:

	4
	3.0
	-1.0
	4.0
	2.0

---------------------------------

	КОДЫ ВОЗВРАТА ПРОГРАММЫ:

	'0' — решение найдено и записано.
	'1' — система несовместна (решений нет).
	'-1' — метод неприменим (вырожденная матрица).
	'100' — не удалось открыть входной файл.
	'111' — не удалось прочесть значение 'n'.
	'112' — некорректное значение 'n'.
	'121' — ошибка выделения памяти под 'A'.
	'122' — ошибка выделения памяти под 'B'.
	'123' — ошибка выделения памяти под 'X'.
	'124' — ошибка выделения памяти под 'tmp'.
	'131' — ошибка чтения значения для матрицы 'A'.
	'132' — ошибка чтения значения для матрицы 'B'.
	'200' — не удалось открыть выходной файл.
	'11' — неизвестная опция.
	'12' — входных файла больше чем два.
	'20' - неизвестная ошибка в  работе программы.
